## Overview

quickQR is a modern Flutter application that allows users to generate, scan, save, and share QR codes effortlessly. Built with performance and simplicity in mind, the app delivers a smooth mobile experience with clean UI and fast QR processing.

The application integrates QR generation, real-time camera scanning, gallery saving, sharing support, permission handling, and URL launching into a lightweight and responsive Flutter app.

---

## Features

| Feature | Description |
|---|---|
| 🔳 Generate QR Codes | Create QR codes instantly from text or custom data |
| 📷 Scan QR Codes | Scan QR codes using the device camera |
| 💾 Save Images | Save generated QR images directly to gallery |
| 🔗 Share QR | Share QR codes using native platform sharing |
| 🖼️ Pick Images | Select images from device storage |
| 🌐 URL Launcher | Open scanned links externally |
| 🔐 Permission Support | Smooth runtime permission handling |
